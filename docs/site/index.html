FAQ

É seguro?

Sim. Cada otimização cria ponto de restauração e pode ser revertida em um clique. O código é aberto no GitHub.

Preciso pagar?

Não. O Capivara Booster é gratuito e open source (MIT).

Funciona no meu Windows?

Windows 10 e 11, 64 bits, com WebView2 (pré-instalado no Windows atualizado).

Por que o SmartScreen avisa?

Porque o instalador open source não tem assinatura de código paga. Confira o SHA-256 na página da release e execute mesmo assim.

Preciso de conta?

Sim, o login é obrigatório. Cadastro restrito a Gmail, Outlook, Yahoo e Yahoo Brasil.
